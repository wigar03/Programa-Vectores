Condición de aplicación

La función debe ser continua en todo $[a,b]$ y sus extremos deben tener signos opuestos. Verifique la continuidad antes de calcular; un cambio de signo también puede deberse a una discontinuidad.

$c=\frac{a+b}{2}$. Si $f(a)$ y $f(c)$ tienen signos opuestos, $b\leftarrow c$; en caso contrario, $a\leftarrow c$. Si $f(c)=0$, el proceso termina.
